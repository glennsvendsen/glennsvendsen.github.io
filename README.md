# www.glennsvendsen.com

Personal site of Glenn Svendsen in Oslo: side projects, notebook sketches and a way to say hello.

Live: [https://www.glennsvendsen.com](https://www.glennsvendsen.com) (glennsvendsen.github.io and glennsvendsen.com redirect there)

Static HTML/CSS/JS, no build step. Deployed to GitHub Pages on every push to `main`.
The contact form's backend is a Cloudflare Worker in [`worker/`](worker/README.md).
